# 📖 Overview

**World Explorer** is a full-stack web application built using **Node.js**, **Express.js**, **EJS**, and **Axios**. It enables users to search for any country and instantly explore essential information such as population, capital, region, continent, currency, languages, driving side, calling code, and national flag.

The project emphasizes **clean UI**, **responsive design**, **server-side rendering**, **API integration**, and **user-friendly error handling**.

# 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/sreeahillan/world-explorer.git
```

### Navigate into the project

```bash
cd world-explorer
```

### Install dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the root directory.

```env
API_KEY=YOUR_API_KEY
```

### Start the application

```bash
npm start
```

Open your browser and visit:

```
http://localhost:3000
```
